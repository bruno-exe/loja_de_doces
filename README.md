# Loja de Doces

## Sobre o projeto

Este projeto está sendo desenvolvido como parte do Projeto Integrador.

A proposta é criar uma plataforma web para facilitar a venda de doces no ambiente de trabalho.

O cliente poderá visualizar os produtos disponíveis, realizar o pedido e efetuar o pagamento online.

Após a compra, o cliente poderá retirar o produto pessoalmente ou receber o doce no local de trabalho.

## Objetivo

Facilitar o processo de venda, pagamento e entrega dos produtos, tornando o atendimento mais organizado, rápido e acessível.

## Funcionalidades previstas

- Visualização dos doces disponíveis
- Cadastro de produtos
- Carrinho de compras
- Realização de pedidos
- Pagamento online
- Comprovante do pedido
- Opção de retirada
- Opção de entrega no local de trabalho
- Controle dos pedidos pelo vendedor
