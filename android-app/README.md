# Come Doce Android

Aplicativo Android Capacitor conectado a `https://comedoce.com.br`.

## Atualizar e abrir

```powershell
cd C:\CD\android-app
npm run android:sync
npm run android:open
```

O servidor FastAPI e o banco de dados continuam hospedados fora do APK.

## Atalhos no Windows

- `abrir_android_studio.cmd`: sincroniza e abre o projeto no Android Studio.
- `gerar_apk_teste.cmd`: gera um APK de teste em `android\app\build\outputs\apk\debug\app-debug.apk`.
